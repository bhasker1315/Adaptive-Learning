Adaptive Learning – Firebase-Enabled Tabs

Developer: Bhasker Muda

📌 Project Overview

A unified Adaptive Learning UI built with Python + Panel and integrated with Firebase Auth, Firestore, and Cloud Storage. The app includes tabs for Bookmarks, Leaderboard, Career, Language, Quiz, and Idea Generator. Each tab uses auth-scoped Firestore reads/writes and runs independently in a single UI.

🚀 Key Features

  • Unified Panel UI: single app with pn.Tabs() and one-time Firebase init
  • Bookmarks & Leaderboard: Firestore read/write + real-time list/rank views
  • Career & Language: Career planning actions and language selector
  • Quiz: progress bar, points (+1/0), answer history table
  • Idea Generator: GPT text, AI image, and PDF export saved to Cloud Storage

🛠️ Technologies

  • Frontend/UI: Python, Panel
  • Backend-as-a-Service: Firebase Auth, Firestore, Cloud Storage
  • Content/Export: OpenAI (text + image), ReportLab (PDF)
  • Dev: GitHub, GitHub Pages
